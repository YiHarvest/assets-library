# 合成素材双路阈值 benchmark

运行 `pnpm benchmark:search`（或 `node --env-file=.env --import tsx benchmarks/search/run.ts`）。
需要 `.env` 中现有的 ES、embedding 配置。整个脚本只连接这两个服务，不连接任何 MySQL。
使用随机生成的 `asset_threshold_bench_*` 临时索引，完成后删除；不会使用配置中的业务索引名。

`dataset.ts` 固定生成 24 个主题、96 条素材、144 个分块和 96 条查询。
每个主题包含两条相关视频素材和两条近似场景干扰素材；三个正查询分别覆盖关键词与自然语言表达，
另有一个不存在合适素材的查询。标签由主体、动作、场景定义，不以 embedding/BM25 输出反推。
视频描述和摘要独立成块；复用业务分块、embedding、两路检索与 RRF 实现。

主题按固定规则划分为 16 个调参主题（64 查询）、8 个测试主题（32 查询），
同一主题的改写不跨集合。语料包含两组素材，但只有调参集的分数和标签参与阈值选择。
不读取业务数据，不生成随机查询，也不调用模型自动裁判。

流程：

1. 生成向量，批量写入新测试索引，核对分块数量。
2. 两路不设阈值，各取当前配置的 Top-K 原始分块，保存实际余弦相似度与 BM25 分数。
3. 调参集联合网格搜索；每组阈值都先独立过滤分块，再调用业务 RRF、素材去重，取前 8 条。
4. 主指标为每查询 F1 的平均（macro F1@8）；空查询正确返回空为 1 分，错误召回为 0。
   同分先选无匹配误召回率更低的组合，再选更低的语义、关键词阈值。
5. 粗搜索：余弦 `[0,1]` 步长 `0.025` 加不限制值 `-1`，BM25 `[0,调参最高分向上取整+1]` 步长 `1`；
   最佳点附近按余弦 `0.005`、BM25 `0.25` 细化。这里的最佳仅指搜索网格内的最优。
6. 固定推荐组合，在测试集评估；全部查询再次调用真实 `searchAssets`，逐项比较素材 ID 顺序和 RRF 分数。

结果写入 `results/`：`report.md` / `report.json` 是结果与限制，`recalls.json` 是原始候选，
`grid.json` 是调参记录。再次运行会覆盖本地结果，但不会自动修改 `.env` 默认值。
报告记录 embedding 模型、维度、ES 版本、分析器、召回窗口以及错误案例。

这是一套小规模、由同一助手编写查询与标签的合成基准，存在表达和标注偏差。
绝不能据此声称在真实业务上有同样准确率。BM25 的绝对分数依赖词频、文档长度与查询长度，
更换模型、分析器或语料后应重新评估。关键词单路与语义单路结果也单独报告，不能把联合最优当成两路各自独立最优。

ES 原始余弦相似度使用 `knn.similarity`；关键词使用 `min_score`。
余弦检索 `_score = (1 + cosine) / 2`，离线评测用 `2 * _score - 1` 还原。
参见 [Elastic kNN 文档](https://www.elastic.co/guide/en/elasticsearch/reference/8.19/knn-search.html)
和 [dense_vector 文档](https://www.elastic.co/guide/en/elasticsearch/reference/8.19/dense-vector.html)。
